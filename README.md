# 🏦 ATM Management System (Java + MySQL)

A console-based ATM Management System developed using **Java** and **MySQL**. This project demonstrates Object-Oriented Programming (OOP), JDBC connectivity, and SQL database operations to perform basic banking transactions through a menu-driven interface.

---

## 🚀 Features

- 🆕 Create a new bank account
- 💰 Deposit money
- 💸 Withdraw money
- 👤 View account details
- 🗄️ Store account information in MySQL
- 🔗 JDBC integration for database connectivity
- 📋 Menu-driven console application

## ⚙️ Installation & Setup

1. Clone the repository

```bash
git clone https://github.com/YourUsername/ATM-Management-System.git
```

2. Import `bank.sql` into MySQL.

3. Update the database credentials in the Java code.

```java
String username = "root";
String password = "your_password";
```

4. Add the MySQL JDBC Driver.

5. Compile and run `PROJECT1.java`.
